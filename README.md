# LoRA Studio

A tiny local web app for preparing Flux LoRA training datasets — without touching
a ComfyUI node graph.

You drop in images, a local vision model writes draft captions, you review them,
and you click **Export**. It outputs:

- A clean dataset folder (images + caption files paired by name)
- A pre-configured ComfyUI FluxTrainer workflow ready to queue

No cloud calls. Captions are generated by a local Ollama model.

## Screenshot

A dark, single-page UI: project list on the left, image grid with editable
captions on the right, four-step progress bar at top (Add → Caption → Review →
Export).

## Requirements

- **Python 3.10+** (standard library only — no `pip install` needed)
- **[Ollama](https://ollama.com)** running locally with a vision model:
  ```bash
  ollama pull llama3.2-vision:11b
  ollama serve
  ```
- **[ComfyUI](https://github.com/comfyanonymous/ComfyUI)** with the
  [FluxTrainer](https://github.com/kijai/ComfyUI-FluxTrainer) custom node, and a
  Flux LoRA training workflow JSON saved somewhere (see `LORA_STUDIO_WORKFLOW_TEMPLATE` below).

## Quick start

```bash
git clone https://github.com/CastilloworksAi/lora-studio.git
cd lora-studio
./start.sh
```

Open <http://127.0.0.1:4173>.

## Configuration (environment variables)

All paths are configurable. Sensible defaults assume a `$HOME/lora_training/`
and `$HOME/ComfyUI/` layout.

| Variable | Default | Purpose |
|---|---|---|
| `LORA_STUDIO_DATASET_ROOT` | `$HOME/lora_training/datasets` | Where exported datasets are written |
| `LORA_STUDIO_OUTPUT_ROOT` | `$HOME/lora_training/output` | Where trained LoRAs will land |
| `LORA_STUDIO_WORKFLOW_TEMPLATE` | `$HOME/lora_training/flux_lora_train.json` | FluxTrainer workflow used as the export template |
| `LORA_STUDIO_COMFY_WORKFLOWS` | `$HOME/ComfyUI/user/default/workflows` | Where the customized workflow is saved |
| `LORA_STUDIO_OLLAMA_URL` | `http://127.0.0.1:11434/api/chat` | Ollama chat endpoint |
| `LORA_STUDIO_VISION_MODEL` | `llama3.2-vision:11b` | Ollama vision model used for captions |
| `LORA_STUDIO_HOST` | `127.0.0.1` | Bind address |
| `LORA_STUDIO_PORT` | `4173` | Bind port |

Example:

```bash
LORA_STUDIO_VISION_MODEL=minicpm-v ./start.sh
```

## Workflow

1. **Create a project.** Pick a subject name and a unique trigger word
   (e.g. `jcstyle01`). The trigger word is the rare token that activates the
   trained LoRA in prompts later.
2. **Add images.** Drag JPG/PNG/WEBP into the dropzone. 20–50 varied images
   works well for a person LoRA.
3. **Caption.** Click *Analyze all images*. Ollama writes a draft caption for
   each one, using your trigger word once per caption.
4. **Review.** Captions are the most important part of training — edit each
   one so it accurately describes only what's visible. Save.
5. **Export.** A dataset folder is written, a copy of the FluxTrainer workflow
   is customized with your dataset path + trigger word, and the result is
   dropped into the ComfyUI workflows folder.
6. **Train.** Open ComfyUI, load the new `lora_studio_<project>_train` workflow,
   press Queue.

## File layout

```
lora-studio/
├── server.py            # Single-file Python HTTP server
├── start.sh             # Launcher
├── static/              # HTML + CSS + vanilla JS frontend
│   ├── index.html
│   ├── app.js
│   └── styles.css
└── projects/            # Per-project working dirs (gitignored)
    └── <slug>/
        ├── project.json
        ├── images/
        └── captions/
```

After export:

- Dataset: `$LORA_STUDIO_DATASET_ROOT/<slug>/`
- Workflow: `$LORA_STUDIO_COMFY_WORKFLOWS/lora_studio_<slug>_train.json`
- Trained LoRA (after training): `$LORA_STUDIO_OUTPUT_ROOT/<slug>/`

## Privacy / security notes

- All paths and the captioning model run **locally**. The browser only talks to
  `127.0.0.1`.
- New files are written with `umask 077` and explicit `chmod 600/700`. Project
  data is yours alone.
- The default bind is `127.0.0.1` — do not change to `0.0.0.0` without
  understanding what that exposes. There is no authentication.
- Only use images you own or have explicit permission to train on.
